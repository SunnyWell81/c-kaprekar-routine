# Kaprekar Routine
C言語で実装したカプレカ操作のシミュレーターです。
3桁以上10桁以下のゾロ目ではない整数を入力すると、固定点または周期に到達するまでの計算過程を表示します。

## 概要
入力された整数の各桁を降順と昇順に並び替え、その差を計算します。この操作を繰り返し、固定点または周期を検出します。
計算履歴に加え、到達した固定点や検出した周期も表示します。

## 学んだこと・意識したこと

### 1. 関数への分割
入力処理、数字の並び替え処理、メイン処理を分けることで、`main()` の処理を読みやすくすることを意識しました。

### 2. 入力処理
`fgets()` と `strtol()` を使用し、入力された文字列を数値に変換する前に、入力の長さや不正な文字、数値の範囲などを確認する処理を実装しました。

### 3. 並び替え処理
選択ソートを使用して、各桁の数字を昇順・降順に並び替えました。
昇順と降順で別々の関数を作るのではなく、引数 `mode` によって比較条件を切り替えることで、処理の重複を減らしました。

### 4. 計算履歴の管理
カプレカ操作の結果を配列に保存し、過去の結果と比較することで、固定点や周期を検出できるようにしました。
また、計算結果をすぐに表示するのではなく、一度配列に保存してから、終了状態に応じて履歴や周期を表示するようにしました。
